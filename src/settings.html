Helios reads i Use Helios for verified RPC reads. Helios verification significantly slows down reads. Read-heavy applications require the faster "trusted" RPC reads.

The sources below only run in Mode 2. A recent target takes Mode 1 unless you force Mode 2 here.

The era source is only consulted for targets older than the BeaconState's rolling block_roots window (8192 slots, ~27h) — newer slots are read straight from the state. Era files and parquet also only exist for completed eras, so pinning either on a block in the current era fails by design; use exec headers there.
